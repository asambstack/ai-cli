How it works

One source of truth, symlinked everywhere.

1

Install

One curl command clones the repo, builds the CLI and dashboard, and creates symlinks to every tool.

2

Scan

ai init reads your project manifests, structure, and git history. Pure static analysis — no API calls.

3

Generate

Produces .ai/context.md with stack, structure, dependencies, and knowledge. Symlinked to each editor's context file.

4

Work

Open any AI editor. Agents, skills, and repo context are available immediately. Describe tasks in natural language.

~/.ai-agents-repo/ agents/*.md ────→ ~/.ai-agents/agents/ skills/*.md ────→ ~/.ai-agents/skills/ claude/commands/ ──→ ~/.claude/commands/*.md claude/rules/ ───→ ~/.claude/rules/common/*.md opencode/ ───→ ~/.config/opencode/opencode.json your-project/.ai/ context.md ────→ CLAUDE.md, .cursorrules, .windsurfrules, ... learnings.md Knowledge persisted across refreshes workspace.md ────→ ../workspace/.ai/context.md
